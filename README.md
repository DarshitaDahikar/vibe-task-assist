TaskPilot — Turn Scattered Messages into a Clear To-Do List

THE PROBLEM
Students and young professionals get important deadlines and responsibilities scattered across WhatsApp messages, emails, and college notices. Nothing gets organized automatically — you have to manually read, remember, and schedule everything yourself.

THE SOLUTION
TaskPilot is an AI assistant that reads any pasted message (a WhatsApp notice, an email, a college announcement) and automatically extracts tasks, deadlines, and events — then tells you exactly what to work on right now, with clear reasoning.

✨ KEY FEATURES :
🤖 AI-Powered Extraction :
- Paste any unstructured message and automatically convert it into structured tasks, deadlines, and events.
🛡️ Mandatory Review & Approve screen :
— nothing gets added without user confirmation, and any item with missing/unclear date info is flagged instead of silently guessed.
📊 Dashboard with Today / Upcoming views and color-coded priority :
- Organize approved items with Today / Upcoming views and color-coded prioritie
🧠 "What should I work on now?" :
 — a one-click decision engine that picks the single best task to focus on and explains why (priority, deadline proximity, estimated time)
⚡ No Login Required :
- Open the app and start using it immediately. Task data is persisted locally using browser local Storage.
📱 Fully Responsive :
- Designed to work across desktop, tablet, and mobile screens.

🛠️TECH STACK
- Frontend: React + TanStack Router, Tailwind CSS
- AI: Groq (Llama 3.3 70B) for natural language extraction and prioritization reasoning
- Storage: Browser localStorage for instant, dependency-free persistence
- Deployment: Vercel
